# Databricks DEA Category Map

## Section 1: Databricks Intelligence Platform（6%）

- Databricks Data Intelligence Platformのアーキテクチャ
- Delta Lake、Unity Catalogなどのコアコンポーネント
- コンピュートサービスの特性、制限、コストモデル

## Section 2: Data Ingestion and Loading（21%）

- バッチ、ストリーミング、増分ロード
- COPY INTO
- Auto Loader
- Lakeflow Connect
- JDBC、ODBC、RESTクライアント
- JSONやネストデータなどの半構造化データ取り込み

## Section 3: Data Transformation and Modeling（22%）

- PySpark / SQLによる変換
- ブロンズ、シルバー、ゴールド
- DataFrame操作、join、union、集計、重複排除
- UDF
- マテリアライズドビュー、ビュー、ストリーミングテーブル
- データ品質制約

## Section 4: Working with Lakeflow Jobs（16%）

- Lakeflow Jobs
- タスク依存関係
- 条件付き実行
- リトライ
- スケジュール、ファイル到着、テーブル更新トリガー
- ジョブ通知

## Section 5: Implementing CI/CD（10%）

- Databricks Git Folders
- Pull Request
- Declarative Automation Bundles / Databricks Asset Bundles
- Databricks CLI
- dev、test、prodへのデプロイ

## Section 6: Troubleshooting, Monitoring, and Optimization（10%）

- Spark UI
- データスキュー
- シャッフル
- メモリ不足
- Liquid Clustering
- Predictive Optimization
- VACUUM、OPTIMIZE
- SQL Warehouseのコスト最適化

## Section 7: Governance and Security（15%）

- Unity Catalog
- マネージドテーブルと外部テーブル
- GRANT、REVOKE、DENY
- USE CATALOG、USE SCHEMA、SELECT、MODIFY
- 列マスク
- 行フィルター
- ABACポリシー
